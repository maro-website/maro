07 · Behavior

Simplify as space narrows

Responsive maro is not a scaled-down desktop. Navigation becomes a drawer, menus become sheets, and creation controls remain reachable.

08 · Quality

Usability is part of the brand

A maro interface is only complete when it works with keyboard, zoom, assistive technology, touch, long Albanian strings, and reduced motion.

AA

Contrast

Essential normal text reaches 4.5:1. Gray 300 never carries meaning alone.

44

Touch targets

Every touch action has at least 44×44px of interactive area.

⌨

Keyboard

Logical order, visible focus, correct semantics, and reliable focus return.

200

Zoom

At 200%, actions stay available and the page never scrolls in two directions.

09 · Handoff

Ready for Cursor

The repository includes an always-on rule, a complete written specification, CSS tokens, and platform-neutral JSON tokens.

  1. 1
    Keep the files together

    Copy this folder into the project or expose it as a shared package.

  2. 2
    Import the token layer

    Load tokens/maro.css once at the app root.

  3. 3
    Let Cursor read the contract

    The included .cursor/rules file points to the canonical specification.

  4. 4
    Review states and breakpoints

    Verify every new screen at the defined viewport sizes before shipping.

Starter prompt
Build this as part of maro.al. Read MARO-DESIGN-SYSTEM.md and tokens/maro.css first. Use only the documented semantic tokens, components, responsive behaviors, interaction states, and accessibility rules. Treat Figma tracking -30 as CSS -0.03em. Reuse the official SVG assets and explain any intentional exception.

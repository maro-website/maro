# Fetch Brand private pilot

The Railway WEB release exposes the importer only to the verified Supabase user ID for `erzen@nice.al`. Both new POST routes also check the verified email, workspace ownership and existing active maroBrain plan. The UI gate is convenience; direct requests from every other account return 404 before any workspace or external-site lookup. There is no public enable flag or admin bypass. A wider rollout requires a separate reviewed change.

In maroBrain → Brendi, submit a public website/domain or accessible social profile. Fetch Brand returns a preview of observed name, description, website, phone, location, language, social channels, literal color suggestions and logo candidates. It reads one homepage and at most two same-origin about/contact pages. It does not infer audience, competitors, goals, business model or missing facts. Blocked social profiles require a website; there is no login bypass. Share images are not treated as logos. Existing nonempty values and the logo are unchecked; checked fields replace those fields only. Channels merge without duplicate URLs. Cancelling does not change the profile. Applying uses the latest editor draft and existing autosave/error handling. Logos upload only after explicit selection and use the existing private storage quota and stable references.

No AI, search API, generation provider or credits are called. Token/provider cost for this feature is zero. Existing Railway bandwidth/CPU and storage still apply. The requested €1/account/month ceiling for future paid agent operations must be implemented with cost reservations before introducing any paid fallback; this pilot has none.

Outbound requests allow only public HTTP(S) on default ports. Every redirect is revalidated; DNS answers are checked and the approved address is pinned into the actual socket. No cookies or authorization are forwarded. Crawl URLs lose queries/fragments. The client never loads raw remote logo URLs or SVG: the protected logo endpoint downloads at most 1 MiB, checks raster signatures or restrictive SVG markup, bounds image dimensions/time and returns a metadata-free PNG. Unsupported/complex SVGs require another candidate or manual upload.

The profile fetch has an 18-second overall deadline, 6.5-second individual request limit, three redirects, 1 MiB homepage and 768 KiB additional-page limits. Logo fetches have a 9-second overall deadline and 16-million-pixel decode limit. Database rate limits are per account across workspaces: profile 12/hour and 40/day; logo 40/hour and 100/day. They fail closed in production. A bounded process cache holds up to 24 results for 15 minutes, keyed by account/workspace/URL; rate limits still apply to cache hits. All API responses are no-store and vary on Authorization.

The only persisted schema addition is an optional `brand.colors` array inside the existing JSON profile; no database migration or environment change is needed. Only user-approved colors join the generation brand brief. The original profile fields, MCP history and existing plan/retention/storage policy continue to apply.

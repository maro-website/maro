The admin home and Analytics page show Online tani, refreshed every 30 seconds while visible. Counts cover the last two minutes. Active browser pages send a heartbeat every 45 seconds, with an eight-second request timeout and backoff on failure; hidden tabs do not poll. This is an approximate session count, not a count of unique humans. Anonymous tabs/reloads may temporarily count separately; verified accounts share one key across tabs/devices. Do Not Track and embedded frames are excluded.

There is no new analytics provider, dependency, paid service, tracking cookie, or local/session storage. The guest UUID exists in page memory only. The server hashes that identifier or the verified account ID with a server-only HMAC; it stores only the hash, login boolean and last-seen timestamp. Presence entries expire from counts after two minutes and are deleted on the next heartbeat or admin read. No historical presence chart, IPs, email addresses, page URLs or prompts are stored in this table. The existing shared rate limiter uses a hashed IP key for abuse protection.

Migration 0065 adds the private RLS-enabled table and service-role-only functions. Public clients can send bounded, same-origin heartbeats through the application but cannot read counts or access the table/RPCs. Admin aggregate reads require analytics.view and the existing MFA gate. A dependency outage shows unavailable (—), never a fabricated zero. No worker, cron or persistent realtime connection is required.
